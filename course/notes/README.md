# Notes

Your learning log.

```
notes/
├── README.md          ← this file
├── glossary.md        ← one-line definitions in your own words
├── 2026-W41.md        ← one file per week (ISO week number)
├── 2026-W42.md
└── papers/            ← one summary per paper (template in track-3-research-engineer/papers.md)
```

## Weekly log template

Copy into `notes/<year>-W<week>.md`:

```markdown
# Week <N> · <date range>

**Track / module:**
**Hours:**   build: _  study: _  write: _

## What I built

## What I learned (explain it as if to a junior engineer)

## What confused me / still don't get

## Numbers
(loss, eval scores, tokens/sec, cost, anything measured)

## Next week
- [ ]
- [ ]
```

## Monthly review (first weekend of each month)

- Am I on pace with the timeline in the top-level README? If not, cut scope rather than skip building.
- Which checkpoint can I *not* yet pass? Go back to that first.
- What did I publish this month? (Aim for at least one write-up per month.)
